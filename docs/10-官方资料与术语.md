## 2. 核心术语

| English | 中文 | 本项目含义 |
|---|---|---|
| Baseline | 基线版本 | 最简单且可评测的第一版 |
| Dataset Version | 数据集版本 | 固定语料快照和实验输入 |
| Ground Truth | 标准标注 | 人工确认的正确答案或 Parent Document |
| Chunk | 文档块 | Retriever 的最小检索单元 |
| Embedding | 向量表示 | 把文本转换为语义向量 |
| Dense Retrieval | 稠密检索/语义检索 | 使用 Embedding 相似度 |
| Sparse Retrieval | 稀疏检索 | 关键词、BM25 等 |
| Hybrid Search | 混合检索 | 组合 Dense 与 BM25 |
| Reranker | 重排序器 | 对候选文档重新精排 |
| Recall | 召回率/查全率 | 正确资料找回多少 |
| Precision | 查准率 | 返回资料中多少正确 |
| MRR | 平均倒数排名 | 第一个正确结果多靠前 |
| Faithfulness | 忠实度/依据性 | 回答是否被证据支持 |
| State | 状态 | LangGraph 节点共享的执行数据 |
| Node | 节点 | 一个明确步骤 |
| Conditional Edge | 条件边 | 根据 State 决定下一节点 |
| Checkpointer | 检查点持久化 | 保存 State 和执行进度 |
| Human-in-the-loop | 人工介入 | 暂停等待人工判断 |
| Idempotency | 幂等 | 重复调用不会产生重复副作用 |
| Migration | 数据库迁移 | 可版本化地改变表结构 |
| Trace | 调用追踪 | 一次请求的节点/模型/工具链路 |
| Regression | 回归 | 修改后旧能力是否退化 |
| ADR | 架构决策记录 | 记录为什么选择某个方案 |

## 3. 查资料原则

遇到 API 问题时：

```text
先确认当前安装版本
→ 查官方文档
→ 查类型提示/源码
→ 写最小可运行示例
→ 再修改项目
```

不要直接复制一年前的博客或课程代码。
